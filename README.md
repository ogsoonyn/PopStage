# PopStage

画像を3D空間に置き、塗った所を平面から持ち上げて、ぷるぷる揺らせる Web アプリです。
「絵を塗って膨らませて揺らす」タイプの懐かしいツールの手触りを、ブラウザだけで動くように作り直しています。

画像とプロジェクトはブラウザ内だけで処理し、サーバーへは送りません。

## 主な機能

- **塗って持ち上げる**: ブラシ・消しゴム・ぼかしでウェイトを塗ると、その場で画像が持ち上がります。筆圧に対応し、レイヤーは最大8枚まで使えます。ポップ量(持ち上げる高さ)は 0〜1500px です。
- **範囲を指定して膨らませる**: 膨らみツール(I)で楕円・矩形をドラッグすると、その範囲が一括で膨らみます。大きさ・高さ(px)・縁のなだらかさ・断面(ドーム / クッション / 直線)を数値で決め、その場でプレビューできます。高さがレイヤーのポップ量を超えるときは、そのレイヤーには触れず、ポップ量 = 高さの新しいレイヤー(膨らみ1 など)に作ります(レイヤーが上限の8枚のときは、ポップ量の高さで止まります)。
- **揺らす**: 揺れのプリセット(ぷるぷる、ばいんばいん、ためてぼよん など)を選ぶか、「つかむ」で画像をドラッグして揺らします。中ドラッグで視点を平行移動したときも、その勢いで揺れます。「揺らす」ツール(Y)で左ドラッグすると、カメラを画像に付けたまま振るので、画像は画面上で動かず揺れだけが見えます。揺らし方ごとの細かい設定や、材質(硬さ・重さ・減衰)も調整できます。揺らし方「ピストン」(プリセット「ずんずん」)では、塗っていない所も含めて画像全体が上下に動き、塗った所はその動きに遅れて付いてきて弾みます(揺れを一時停止・ポップを一時OFF の間は画像も元の位置に止まります)。揺らし方「ためて膨らむ2」(プリセット「ぷっくり」)では、手前へ膨らむだけでなく、塗った範囲も中心から外へ広がるように膨らみます。広がる中心はそのレイヤーのウェイトの重心なので、離れた所を別々に広げたいときはレイヤーを分けてください。塗りの縁をぼかしておくと、広がったときの縁がきれいです。
- **細かく動かす**: 回転・平行移動・ズーム・つかむ・揺らす・3面図の操作は、Ctrl か Shift を押しながらだと動きが 1/5 になります(3面図の自由角度の Shift+ドラッグは平行移動なので、そこでは Ctrl)。
- **見やすい表示**: ウェイトの重ね表示、画像を薄く、ポップを一時OFF、揺れを一時停止、3面図(正面・右から・下から・自由角度)を切り替えられます。3面図はそれぞれホイールでズーム、ドラッグで平行移動(自由角度はドラッグで回転、中ドラッグか Shift+ドラッグで平行移動)、ダブルクリックで元に戻せます。自由角度の視点はプロジェクトに保存します(正面・右から・下からの拡大と平行移動は保存しません)。左のメニューの「表示クリア」(編集表示クリア、C)で、重ね表示・画像を薄く・ポップを一時OFF・揺れを一時停止・グリッドをまとめて切り、見栄えを確かめられます。
- **よく使う操作の置き場所**: 選択中のレイヤー向けの「全体ぼかし・正規化・反転」は左のメニューに、「揺れ」「自動で揺らす」の切り替えは上のツールバーにもあります。
- **最近開いたファイル**: 開いた・保存したファイルを縮小画像付きで一覧にし、そこから開き直せます(ファイル → 最近開いたファイル…)。一覧はブラウザの中だけに残ります。Chrome / Edge ではファイルの場所を、ほかのブラウザでは中身のコピー(1件 50MB まで)を覚えます。
- **書き出し**: MP4 / WebM / 透過WebM / 連番PNG(ZIP) / GIF に書き出します。1フレームずつ物理を進めて描くので、PC の負荷に関係なくコマ落ちしません。自動の揺れのほか、直前の操作を再生して書き出すこともできます。
- **保存**: `.popstage` 形式(ZIP に設定・画像・ウェイトをまとめたもの)で保存します。作業中の内容はブラウザ内に自動保存し、次回の起動時に復元できます。

## 動作環境

デスクトップ版の Chrome / Edge の最新版を想定しています。

| 機能 | 必要なもの |
| --- | --- |
| 表示・編集 | WebGL2 |
| MP4 / WebM の書き出し | WebCodecs |
| 透過WebM の書き出し | アルファ付き VP9 のエンコード(Chromium 系) |
| 上書き保存 | File System Access API(無い場合はダウンロードで保存) |

Firefox と Safari での動作は確認していません。

## 使い方

1. 画像(PNG / JPEG / WebP)をウィンドウへドロップします。起動時はサンプル画像が開きます。
2. ブラシ(B)で動かしたい所を塗ります。塗った所がその場で持ち上がります。
3. 右ドラッグで視点を回し、右パネルでポップ量や揺れのプリセットを調整します。
4. つかむ(G)で画像をドラッグするか、中ドラッグで画像を動かして揺らします。
5. Ctrl+E で動画や画像に書き出し、Ctrl+S で `.popstage` に保存します。

操作の一覧はアプリの「ヘルプ → 操作方法」にあります。

## 開発

Node.js 20.19 以降(または 22.12 以降)が必要です。

```sh
npm install
npm run dev        # 開発サーバーを起動する
npm run build      # 型チェックのあと dist/ へ静的ファイルを出力する
npm run preview    # ビルド結果を確認する
npm test           # 単体テスト(Vitest)
npm run e2e        # E2E テスト(Playwright)
```

ビルド結果は相対パスで参照し合うので、`dist/` の中身をそのまま任意の静的ホスティングに置けば動きます。

### 使っている主なライブラリ

| 用途 | ライブラリ |
| --- | --- |
| 描画 | [three.js](https://threejs.org/) |
| 画面 | [Tailwind CSS](https://tailwindcss.com/)、[daisyUI](https://daisyui.com/) |
| 動画の書き出し | [Mediabunny](https://mediabunny.dev/)(WebCodecs) |
| GIF の書き出し | [gifenc](https://github.com/mattdesl/gifenc) |
| ZIP | [fflate](https://github.com/101arrowz/fflate) |
| ビルド・テスト | [Vite](https://vite.dev/)、[Vitest](https://vitest.dev/)、[Playwright](https://playwright.dev/) |

### 構成

`model` / `commands` / `paint` / `physics` / `storage` は DOM と three.js を参照しないので、ブラウザ無しで単体テストできます。

| ディレクトリ | 役割 |
| --- | --- |
| `src/model` | ドキュメントモデル(Project / Document / Layer)、ウェイトマップ、変更通知 |
| `src/commands` | 変更操作とアンドゥ(100手 / 256MB まで。塗りは 64px タイルの差分で持つ) |
| `src/paint` | ストローク処理(補間、ブラシ・消しゴム・ぼかし、筆圧)、範囲を指定して膨らませる処理 |
| `src/physics` | 揺れの計算(レイヤーごとのバネ・ダンパ、固定 120Hz)、揺らし方のパターン、操作の記録 |
| `src/stage` | three.js の描画。ウェイトをテクスチャ配列にまとめ、頂点シェーダで持ち上げる |
| `src/storage` | `.popstage` の読み書き、IndexedDB への自動保存 |
| `src/export` | フレーム単位の書き出し |
| `src/ui` | 画面の部品(入力、パネル、ダイアログ、3面図) |
| `src/app.ts` | 各モジュールをつなぐ本体 |

### テスト

- **単体テスト**(`tests/unit`): ウェイトマップの各操作、アンドゥの往復と上限、ストローク、物理の収束・周期性、PNG と `.popstage` の読み書きを確かめます。
- **E2E テスト**(`tests/e2e`): 起動、塗りとアンドゥ、視点操作、レイヤー操作、プリセット、表示の切り替え、保存と読み込み、各形式の書き出しを実際のブラウザで確かめます。

E2E テストは、インストール済みの Google Chrome を使います(`playwright.config.ts` の `channel: 'chrome'`)。描画は SwiftShader で行うので、GPU が無い環境でも動きます。

見た目の比較に使う基準画像は OS ごとに別のファイルになります。使っている OS 用の基準画像が無いときは、初回に次のコマンドで作成してください。

```sh
npx playwright test --update-snapshots
```

## 既知の制限

- 透過画像を横から見ると、画像の縁が引き伸ばされて見えます。
- 揺れはレイヤー単位で計算しています。頂点ごとに異なる揺れ方はしません。
- ウェイトは 8 ビットで持つので、ポップ量を非常に大きくすると段差が見えることがあります。
