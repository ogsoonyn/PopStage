# PopStage(仮称)

画像を3D空間に置き、塗った所を平面から持ち上げ、さらに揺らせるWebアプリです。TypeScript + Three.js で作っています。操作感の元になったモックは `PopStage_Mockup/` にあります。

画像とプロジェクトはブラウザ内だけで処理し、サーバーへは送りません。

## 使い方

```sh
npm install        # 依存パッケージ(プロジェクト内の node_modules のみ)
npm run dev        # 開発サーバー http://localhost:5173
npm run build      # 型チェック + dist/ へ静的ファイルを出力(相対パスなのでどこに置いても動く)
npm test           # 単体テスト(Vitest、ブラウザ不要)
npm run e2e        # E2Eテスト(Playwright、手元の Google Chrome を使う)
```

1. 画像(PNG / JPEG / WebP)をウィンドウへドロップする。起動時はサンプル(プリン)が開く。
2. ブラシ(B)で動かしたい所を塗る。塗った所がその場で持ち上がる。
3. 右ドラッグで視点を回し、右パネルでポップ量や揺れのプリセットを調整する。
4. つかむ(G)で画像をドラッグして揺らす。
5. Ctrl+E で MP4 / WebM / 透過WebM / 連番PNG / GIF に書き出す。Ctrl+S で `.popstage` に保存する。

操作の一覧はアプリの「ヘルプ → 操作方法」にあります。

## 構成

設計書3章のモジュール分割に沿っています。`model` / `commands` / `paint` / `physics` / `storage` は DOM と Three.js を参照しないので、Vitest でブラウザ無しにテストできます。

| ディレクトリ | 役割 |
| --- | --- |
| `src/model` | ドキュメントモデル(Project / Document / Layer)、ウェイトマップ、変更通知 |
| `src/commands` | 変更操作とアンドゥスタック(100手 / 256MB、塗りは 64px タイルの差分) |
| `src/paint` | ストローク処理(25% 間隔の補間、ブラシ・消しゴム・ぼかし、筆圧) |
| `src/physics` | 揺れA案(レイヤー単位のバネ・ダンパ、固定120Hz)、自動揺らし、操作の記録 |
| `src/stage` | Three.js の描画。ウェイト8枚をテクスチャ配列にまとめ、頂点シェーダで持ち上げる |
| `src/storage` | `.popstage`(ZIP + project.json + PNG)の読み書き、IndexedDB の自動保存 |
| `src/export` | フレーム単位の書き出し(WebCodecs + mediabunny、gifenc、fflate) |
| `src/ui` | 画面の部品(入力、パネル、書き出しダイアログ) |
| `src/app.ts` | 上の各モジュールをつなぐ本体 |

## フェーズ0の検証結果

| 項目 | 結果 |
| --- | --- |
| WebCodecs でフレーム単位の MP4 / WebM 書き出し | Chrome で可。書き出した 2秒・60fps の MP4 / WebM が `<video>` で 120 フレームとして再生できることを確認 |
| 透過付き WebM をブラウザだけで出せるか | Chrome で可(VP9 + α)。読み戻して透明画素が残っていることを確認 |
| 2000px級の画像、密度256で60fps | RTX 3090 で 2048×1536・密度512・4レイヤーでも 5,000fps 超(上限解除で計測)。低性能な GPU では未計測 |
| 塗った矩形だけテクスチャへ転送できるか | 可。`texSubImage3D` で部分転送している(E2Eテストで確認) |
| 8ビットのウェイトで段差が見えないか | ポップ量 140px ではレベル間の差が 1px 未満。大きなポップ量での見え方は目視での確認が必要 |
| 揺れA案の見え方、B案の性能 | A案を実装。B案(頂点単位)は未着手 |
| 透過画像の縁 | 持ち上げた状態でも縁はなめらかに描ける。横から見ると縁が引き伸ばされる(設計書11章の既知のリスクどおり) |
| Firefox での動作 | 未確認 |

## テスト

- 単体テスト 37件: ウェイトマップの各コマンド、アンドゥの往復と上限、タイル差分、ストローク、物理の収束・減衰・周期性、記録、PNG の往復、`.popstage` の往復と不正値の丸め。
- E2E 15件: 起動、塗りとアンドゥ、視点、つかみ、レイヤー操作、スライダーのアンドゥ、保存→読込、5形式の書き出し、操作の再生、背景色、基準画像との比較。

基準画像(`tests/e2e/app.spec.ts-snapshots/`)は Windows の SwiftShader で撮ったものです。別の環境では `npx playwright test --update-snapshots` で撮り直してください。
