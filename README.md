# PukuPop

画像を3D空間に置き、塗った所を平面から持ち上げて、ぷるぷる揺らせる Web アプリです。
「絵を塗って膨らませて揺らす」タイプの懐かしいツールの手触りを、ブラウザだけで動くように作り直しています。

画像とプロジェクトはブラウザ内だけで処理し、サーバーへは送りません。

## 主な機能

- **塗って持ち上げる**: ブラシ・消しゴム・ぼかしでウェイトを塗ると、その場で画像が持ち上がります。筆圧に対応し、レイヤーは最大8枚まで使えます。ポップ量(持ち上げる高さ)は 0〜1500px です。
- **範囲を指定して膨らませる**: 膨らみツール(I)で楕円・矩形をドラッグすると、その範囲が一括で膨らみます。大きさ・角度・高さ(px)・縁のなだらかさ・断面(ドーム / クッション / 直線)を数値で決め、その場でプレビューできます。角度(-90°〜90°、正で時計回り)を付けると形が傾き、傾けたままドラッグすると始点と終点が傾いた形の対角の角になります。形・断面・縁のなだらかさ・角度・重ね方は、描く前に上のツールオプションの欄でも選べます(ブラウザに覚えます)。高さがレイヤーのポップ量を超えるときは、そのレイヤーには触れず、ポップ量 = 高さの新しいレイヤー(膨らみ1 など)に作ります(レイヤーが上限の8枚のときは、ポップ量の高さで止まります)。
- **複数のレイヤーをまとめて変える**: レイヤー一覧で Ctrl(⌘)+クリックで足す・外す、Shift+クリックで範囲、Ctrl+A で全部を選び、Esc で1枚に戻します(スマホは長押しで選択モードに入り、タップで足す・外します)。レイヤータブの項目(ポップ量・重ね方・揺れ・プリセット・揺らし方・材質)と、全体ぼかし・正規化・反転・全消去・アルファから生成・複製・削除は、選んだ全部に効き、まとめて1手で元に戻せます。値が揃っていない項目は「混在」と出し、変えた項目だけを全部に書きます。ポップ量は一番高いレイヤーの値を出し、ほかは同じ比率で伸び縮みします(0px のレイヤーは 0px のまま)。揺らし方ごとの設定は、揺らし方が揃っているときだけ出します。塗り・膨らみは最後に押したレイヤー(左に太い線)だけにかかり、表示のチェックと並べ替えは1枚ずつです。一覧には、重ね表示の色の印と、重ね方のアイコン(加算: 山の上に山を積んだ形、最大: 2つの山をつないだ外形)を出します。
- **揺らす**: 揺れのプリセット(ぷるぷる、ばいんばいん、ためてぼよん など)を選ぶか(揺れているレイヤーがそのレイヤーだけのときは、自動揺らしの周期もおすすめの値にします。ほかにも揺れているレイヤーがあるときは、周期は変えずに知らせます)、「つかむ」で画像をドラッグして揺らします。中ドラッグか「移動」ツール(H)で視点を平行移動したときも、その勢いで揺れます。「揺らす」ツール(Y)で左ドラッグすると、カメラを画像に付けたまま振るので、画像は画面上で動かず揺れだけが見えます。揺らし方ごとの細かい設定や、材質(硬さ・重さ・減衰)も調整できます。揺らし方「ピストン」(プリセット「ずんずん」)では、塗っていない所も含めて画像全体が上下に動き、塗った所はその動きに遅れて付いてきて弾みます(揺れを一時停止・ポップを一時OFF の間は画像も元の位置に止まります)。揺らし方「ためて膨らむ2」(プリセット「ぷっくり」)では、手前へ膨らむだけでなく、塗った範囲も中心から外へ広がるように膨らみます。広がる中心はそのレイヤーのウェイトの重心なので、離れた所を別々に広げたいときはレイヤーを分けてください。塗りの縁をぼかしておくと、広がったときの縁がきれいです。
- **操作の記録とループ再生**: 右パネルの「アニメーション」タブにある「操作の記録」(スマホはシートの「アニメ」タブ)で「記録」(R)を押すか、メニューの「アニメーション」から始め、つかむ・揺らす・移動・視点で動かしてから止めると、その操作を覚えます(最長 60 秒)。「ループ再生」(L)でくり返し再生し、画面を触ると止まります。初めの何もしていない所は詰め、終わりは初めの視点へなめらかに寄せるので、継ぎ目で視点が飛びません。記録は `.pukupop` に保存し、書き出しの「記録した操作をループ再生」で、揺れの継ぎ目まで揃ったループ動画にできます(自動の揺れと重ねて動きます)。記録はアンドゥで戻せます。
- **右パネルのタブ**: 右パネルは、効く範囲ごとに「レイヤー」(選んでいるレイヤーのポップ量・重ね方・揺れ・プリセット)、「アニメーション」(自動揺らし・操作の記録・キーフレーム)、「画像と表示」(メッシュ密度・不透明度・表示の切り替え・画角・背景)のタブに分かれています。スマホのシートも同じ分け方です(「レイヤー」「アニメ」「表示」)。レイヤー一覧はタブの上に常に出ています。各項目の説明は、項目の横の「?」で開きます。
- **キーフレーム**: 「アニメーション」タブの「キーフレーム」で、「＋ 追加」で今の視点(回転・ズーム・画像の位置)を足していき、フレームごとに次までの時間(0.1〜5 秒)と通り方(なめらか: 止まらず通り抜ける / 弾む: 急に止まって揺れる)を決めます。「作成して再生」で、フレームを順に通って最後から最初へ戻る動きを作り、ループ再生します(最大 12 個)。画像の位置が動くと、その勢いで揺れます。作った動きは操作の記録と同じように保存・書き出しでき、キーフレームも一緒に保存するので作り直せます。
- **お気に入り**: いい揺れや動きを見つけたら、「アニメーション」タブの「お気に入り」の「☆ 残す」(K。左のツールバーにもあります)で、その組み合わせを残せます。残すのは全レイヤーのポップ量・重ね方・揺れ、自動揺らし、操作の記録とキーフレーム、視点で、画像とウェイトは残さないので、同じ画像のファイルを別名で増やさずに試し比べられます。「適用」でその組み合わせに戻り(視点のほかは元に戻せます)、名前の変更・今の状態での上書き・削除もその場でできます(最大 30 件)。今の状態と同じものには ● が付きます。お気に入りは `.pukupop` に保存するので、ファイルを持っていけばほかの端末でも使えます。
- **細かく動かす**: 回転・平行移動・ズーム・つかむ・揺らす・3面図の操作は、Ctrl か Shift を押しながらだと動きが 1/5 になります(3面図の自由角度の Shift+ドラッグは平行移動なので、そこでは Ctrl)。
- **見やすい表示**: ウェイトの重ね表示(OFF / 選択中 / 全レイヤーの3つ。全レイヤーは表示中のレイヤーをそれぞれの色で重ね、選んでいないものは薄くします。W と左のツールバーの「ウェイト」は押すたびに順に切り替えます)、画像を薄く、ポップを一時OFF、揺れを一時停止、3面図(正面・右から・下から・自由角度)、グリッドを切り替えられます。3面図はそれぞれホイールでズーム、ドラッグで平行移動(自由角度はドラッグで回転、中ドラッグか Shift+ドラッグで平行移動)、ダブルクリックで元に戻せます。自由角度の視点はプロジェクトに保存します(正面・右から・下からの拡大と平行移動は保存しません)。3面図・ウェイトの重ね表示・画像を薄く・グリッドは、左のツールバーからも切り替えられます。ブラシ・消しゴム・ぼかし・膨らみに切り替えたときや「全体をぼかす」を開いたときは、重ね表示が OFF なら「選択中」にします(「画像と表示」タブの「塗るときは自動でON」で切れます。ブラウザに覚えます)。左のツールバーの「表示クリア」(編集表示クリア、C)で、重ね表示・画像を薄く・ポップを一時OFF・揺れを一時停止・グリッドをまとめて切り、見栄えを確かめられます。
- **よく使う操作の置き場所**: 左のツールバーには、ツールのほかに、よく使う操作(「3面図」「ウェイト」(重ね表示)「画像を薄く」「グリッド」「表示クリア」と、選択中のレイヤー向けの「全体ぼかし・正規化・反転」、お気に入りに残す「お気に入り」)も置いています。押すと選んだ状態になるツールは塗りつぶしのボタン、押すとその場で効く操作は点線の枠の中のボタンです(表示の切り替えは、入のときに淡い色と枠が付きます)。画面の高さが足りないときは、操作のボタンからアイコンを隠して詰めます。「揺れ」「自動で揺らす」の切り替えは上のツールバーにもあります。
- **最近開いたファイル**: 開いた・保存したファイルを縮小画像付きで一覧にし、そこから開き直せます(ファイル → 最近開いたファイル…)。一覧はブラウザの中だけに残ります。Chrome / Edge ではファイルの場所を、ほかのブラウザでは中身のコピー(1件 50MB まで)を覚えます。
- **書き出し**: MP4 / WebM / 透過WebM / 連番PNG(ZIP) / GIF に書き出します。1フレームずつ物理を進めて描くので、PC の負荷に関係なくコマ落ちしません。自動の揺れのほか、直前の操作の再生や、記録した操作のループ再生を書き出すこともできます。
- **保存**: `.pukupop` 形式(ZIP に設定・画像・ウェイトをまとめたもの)で保存します。改名前の `.popstage` ファイルもそのまま開けます。作業中の内容はブラウザ内に自動保存し、次回の起動時に復元できます。

- **スマホ**: 幅が狭い画面では、3Dビューを全面に出し、ツールは下のバー(つかむ・揺らす・移動・視点)、設定は下から引き上げるシートにまとめます。1本指で選んだツール(画像の外では回転。「移動」では画像の外でも平行移動)、2本指で平行移動とピンチズーム、2本指タップで元に戻す、3本指タップでやり直します。膨らみ・塗り・消しゴム・ぼかしはシートの「レイヤー」→「塗って直す」から使います。

## 動作環境

デスクトップ版の Chrome / Edge の最新版を想定しています。スマホは Android の Chrome で確かめています。

| 機能 | 必要なもの |
| --- | --- |
| 表示・編集 | WebGL2 |
| MP4 / WebM の書き出し | WebCodecs |
| 透過WebM の書き出し | アルファ付き VP9 のエンコード(Chromium 系) |
| 上書き保存 | File System Access API(無い場合はダウンロードで保存) |

Firefox と Safari での動作は確認していません。

### ホーム画面に追加する

アプリとしてホーム画面に置けます。一度開いたあとは、電波がなくても起動できます。

- Android(Chrome): メニューの「ホーム画面に追加」または「アプリをインストール」
- iPhone / iPad(Safari): 共有ボタンから「ホーム画面に追加」

## 使い方

1. 画像(PNG / JPEG / WebP)をウィンドウへドロップします。起動時はサンプル画像が開きます。
2. ブラシ(B)で動かしたい所を塗ります。塗った所がその場で持ち上がります。
3. 右ドラッグで視点を回し、右パネルでポップ量や揺れのプリセットを調整します。
4. つかむ(G)で画像をドラッグするか、中ドラッグで画像を動かして揺らします。
5. Ctrl+E で動画や画像に書き出し、Ctrl+S で `.pukupop` に保存します。

操作の一覧はアプリの「ヘルプ → 操作方法」にあります。

## 開発

Node.js 20.19 以降(または 22.12 以降)が必要です。

```sh
npm install
npm run dev        # 開発サーバーを起動する
npm run build      # 型チェックのあと dist/ へ静的ファイルを出力する
npm run preview    # ビルド結果を確認する
npm test           # 単体テスト(Vitest)
npm run e2e        # E2E テスト(Playwright)
```

アプリアイコンは `scripts/icon-art.mjs` の SVG から作ります。絵を変えたら `node scripts/make-icons.mjs` で `public/icons/` の画像を作り直してください。service worker は `public/sw.js` で、本番ビルドのときだけ登録します(`?e2e` 付きのときも登録しません)。

画面まわりは、次の表を1か所で持ち、ほかはそこから作ります。部品を足したり名前を変えたりするときは、まずここを直してください。

| 何を | どこに |
| --- | --- |
| 画面の要素の id と種類(起動時にまとめて取り、合わなければ止まる。`index.html` との突き合わせは単体テスト) | `src/ui/ids.ts` |
| コマンド(名前・ショートカット・使える条件)。メニューのキー表記・ツールチップ・ヘルプのキー一覧・キーの処理はここから作る | `src/ui/actions.ts` |
| 左のツールバーのツール(名前・キー・ヒント)。スマホの下のバーもアイコンと名前はここから | `src/ui/tools.ts` |
| 左のツールバーの、その場で効く操作のまとまり | `src/ui/actions.ts` の `NAV_ACTIONS` |
| アイコン(PC とスマホで共通) | `src/ui/icons.ts` |
| 項目の説明(「?」で開く。`data-help` に説明の id) | `src/ui/help.ts` |
| スマホのシートへ移す部品(`index.html` の `data-m-slot` と、移す先のタブ) | `src/ui/mobile.ts` の `MOBILE_SLOTS` |

ビルド結果は相対パスで参照し合うので、`dist/` の中身をそのまま任意の静的ホスティングに置けば動きます。

`main` へ push すると、GitHub Actions(`.github/workflows/deploy-pages.yml`)がテストとビルドを行い、GitHub Pages へ公開します。初回だけ、リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください。

### 構成

`model` / `commands` / `paint` / `physics` / `storage` は DOM と three.js を参照しないので、ブラウザ無しで単体テストできます。

| ディレクトリ | 役割 |
| --- | --- |
| `src/model` | ドキュメントモデル(Project / Document / Layer)、ウェイトマップ、変更通知 |
| `src/commands` | 変更操作とアンドゥ(100手 / 256MB まで。塗りは 64px タイルの差分で持つ) |
| `src/paint` | ストローク処理(補間、ブラシ・消しゴム・ぼかし、筆圧)、範囲を指定して膨らませる処理 |
| `src/physics` | 揺れの計算(レイヤーごとのバネ・ダンパ、固定 120Hz)、揺らし方のパターン、操作の記録 |
| `src/stage` | three.js の描画。ウェイトをテクスチャ配列にまとめ、頂点シェーダで持ち上げる |
| `src/storage` | `.pukupop`(旧 `.popstage`)の読み書き、IndexedDB への自動保存 |
| `src/export` | フレーム単位の書き出し |
| `src/ui` | 画面の部品(入力、パネル、ダイアログ、3面図) |
| `src/app.ts` | 各モジュールをつなぐ本体 |

### テスト

- **単体テスト**(`tests/unit`): ウェイトマップの各操作、アンドゥの往復と上限、ストローク、物理の収束・周期性、PNG と `.pukupop`(旧 `.popstage`)の読み書きを確かめます。
- **E2E テスト**(`tests/e2e`): 起動、塗りとアンドゥ、視点操作、レイヤー操作、プリセット、表示の切り替え、保存と読み込み、各形式の書き出しを実際のブラウザで確かめます。機能ごとにファイルを分けています(`paint`・`view`・`physics`・`storage`・`export`・`ui`・`layers`・`take`・`favorites`・`mobile`)。共通の道具(起動・WebGL のエラーの見張り・3Dビューでのドラッグなど)は `tests/e2e/helpers.ts` にあります。

E2E テストは、インストール済みの Google Chrome を使います(`playwright.config.ts` の `channel: 'chrome'`)。描画は SwiftShader で行うので、GPU が無い環境でも動きます。

見た目の比較に使う基準画像は OS ごとに別のファイルになります。使っている OS 用の基準画像が無いときは、初回に次のコマンドで作成してください。

```sh
npx playwright test --update-snapshots
```

## 既知の制限

- 透過画像を横から見ると、画像の縁が引き伸ばされて見えます。
- 揺れはレイヤー単位で計算しています。頂点ごとに異なる揺れ方はしません。
- ウェイトは 8 ビットで持つので、ポップ量を非常に大きくすると段差が見えることがあります。
